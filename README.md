# floortopia
Floortopia is a UI theme for Floorp browser userChrome.css

INSTALLATION

- in Floorp copy the userChrome.css to your default profile folder.
- also choose either purple, green, or gradient glass tabs.
- copy the png to the default profile folder as tab-glass.png
- the URL input is inspired by the old ios5 'slide to unlock'
- glass from ios5/vista days
